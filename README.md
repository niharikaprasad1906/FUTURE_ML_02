# 🎫 AI-Powered Support Ticket Classifier

## Project Overview
This project develops an AI-powered system to automatically classify and prioritize customer support tickets. Utilizing natural language processing (NLP) and machine learning models, the system aims to streamline customer support operations by quickly identifying ticket categories and urgency, and suggesting appropriate actions.

The core of the project is a Gradio web application that provides an interactive interface for testing the classifier.

## Features
- **Automated Ticket Classification:** Categorizes incoming support tickets into one of five types: Technical issue, Billing inquiry, Refund request, Product inquiry, or Cancellation request.
- **Priority Assignment:** Assigns a priority level (High, Medium, Low) to each ticket.
- **Action Suggestion:** Provides intelligent action suggestions based on the predicted category and priority to guide support agents.
- **Interactive Web Interface:** A user-friendly Gradio interface allows for easy testing and demonstration of the classifier.
